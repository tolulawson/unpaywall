# unpaywall

To install dependencies:

```bash
bun install
```

To build the extension:

```bash
bun run build
```

Then load the `dist/` folder as an unpacked Chrome extension.

Usage:

- Click the toolbar button to open the current page in Unpaywall.
- Right-click a link and choose `Open via Unpaywall` to open that link in a new tab via Unpaywall.

This project was created using `bun init` in bun v1.2.8. [Bun](https://bun.sh) is a fast all-in-one JavaScript runtime.
